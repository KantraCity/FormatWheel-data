# Format Wheel — расширение «Данные»

Конвертация структурированных данных для [Format Wheel](https://github.com/KantraCity/FormatWheel): JSON, YAML, XML, TOML и CSV в любую сторону.

- **Вход:** JSON (и JSONC с комментариями), YAML/YML, XML, TOML, CSV/TSV.
- **Shift — формат:** JSON, YAML, XML, TOML, CSV. Без выбора JSON уходит в YAML, остальное в JSON.
- **Ctrl+Shift — вид:** «Красиво» (с отступами) или «Сжато» (в одну строку). Работает для JSON и XML.
- **Alt+Shift — ключи:** как есть или по алфавиту (рекурсивно).

Никаких внешних программ не нужно, всё внутри DLL.

## Как сопоставляются форматы

Всё читается в общее дерево (объекты, массивы, строки, числа, true/false, null) и пишется из него.

- **YAML:** значения без кавычек получают тип (`42` — число, `true` — логическое), в кавычках остаются строками. При записи строка вроде `"007"` или `"true"` берётся в кавычки, чтобы не превратиться в число. Несколько документов через `---` превращаются в массив.
- **XML:** атрибуты пишутся как `@имя`, текст рядом с вложенными элементами — как `#text`, повторяющиеся элементы — как массив. Если у объекта больше одного ключа сверху, он оборачивается в `<root>`, элементы массива — в `<item>`.
- **TOML:** в TOML нет `null`, поэтому такие ключи пропускаются. Если в корне не объект, он кладётся под ключ `items`. Массивы объектов пишутся как `[[секции]]`.
- **CSV:** первая строка — заголовки, разделитель (`,` `;` таб `|`) определяется сам. При записи вложенные объекты становятся колонками `a.b`, а массивы — JSON-строкой в ячейке. Файл сохраняется в UTF-8 с BOM, чтобы Excel нормально открыл кириллицу.
- Числа вроде `007` или `+7` остаются строками, чтобы не терять ведущие нули в индексах и телефонах.

## Установка

1. Сначала поставьте саму программу Format Wheel.
2. Запустите `FormatWheel-Data-Setup-x.y.z.exe` из релизов.
3. В Format Wheel откройте меню трея → «Расширения» → «Перезагрузить расширения» (или перезапустите программу).

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Нужны [.NET 10 SDK](https://dotnet.microsoft.com/download) и пакет `FormatWheel.Sdk`. На nuget.org его пока нет: возьмите `FormatWheel.Sdk.x.y.z.nupkg` из [релизов FormatWheel-app](https://github.com/KantraCity/FormatWheel-app/releases) (или соберите `dotnet pack src/FormatWheel.Sdk` в репозитории программы) и подключите папку с ним как источник: `dotnet nuget add source C:\путь\к\папке -n formatwheel-sdk`. GitHub Actions делает это сам. Inno Setup скрипт поставит через winget, если его нет.

Зависимости: [YamlDotNet](https://github.com/aaubry/YamlDotNet) и [Tomlyn](https://github.com/xoofx/Tomlyn) (обе MIT), ставятся вместе с расширением.
